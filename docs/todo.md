# 未来方向 (Backlog)

> MVP 阶段只做了**方向 2 (文书生成)**。以下是后续可扩展的方向, 记录待办。

## 方向 1: 证据收集

### 截图/录屏存证

- [ ] 抓取网页并截图 (playwright/puppeteer)
- [ ] 命令行触发 ffmpeg 录屏
- [ ] 抓取时记录元数据 (URL / User-Agent / 时间戳 / IP)
- [ ] 自动计算文件 hash (SHA-256) 用于完整性证明

### 网页归档

- [ ] WARC 格式归档 (符合互联网档案标准)
- [ ] 集成 archive.org / 中国互联网档案
- [ ] 生成 hash 证据链文件 (txt 含 URL + 时间 + hash)

### 与案件绑定

- [ ] `dsh evidence add <case-id> --kind screenshot --file xxx.png`
- [ ] 案件目录下 `evidence/` 自动按编号归档
- [ ] 自动生成证据目录初稿 (与方向 2 复用)

## 方向 4: 法律检索

### 裁判文书检索

- [ ] 中国裁判文书网 (wenshu.court.gov.cn) 集成
- [ ] 威科先行 / 北大法宝 / 百度民法典 集成
- [ ] 按"侵权类型 + 判决结果 + 地区"筛选

### 法条匹配

- [ ] 侵权内容 → 适用法条推荐 (基于关键词+LLM)
- [ ] 民法典 1024/1025/1183 等核心条款的解读文档
- [ ] 类案胜诉/败诉率统计

### 检索结果导出

- [ ] `dsh search case --type 网络侵权 --court 北京` 输出 markdown
- [ ] 检索结果链接到案件 (作为参考资料)

## 方向 5: 调解谈判

### 律师函强化 (与方向 2 复用)

- [ ] 多种律师函风格: 温和 / 强硬 / 折中
- [ ] 律师函模板按侵权类型分类: 微博 / 抖音 / 朋友圈 / 传统媒体

### 协商话术

- [ ] 协商话术模板 (5 种风格: 温和/坚定/强硬/折中/最终通牒)
- [ ] 电话/微信/线下沟通脚本生成

### 赔偿计算

- [ ] 精神损害抚慰金计算器 (基于侵权程度、影响范围、过错程度)
- [ ] 合理维权支出计算 (公证费、律师费、差旅费)
- [ ] 给出数额区间 (低/中/高) 供参考

### 谈判记录

- [ ] 案件目录下 `negotiations/` 记录每次沟通
- [ ] 关键时间节点提醒 (律师函期满未回应 → 起诉)
- [ ] 调解协议草稿生成

---

## 优先级建议

**MVP 之后, 推荐先做方向 1 (证据收集)**:
- 证据是诉讼的根基, 没有证据文书就是空中楼阁
- 技术上与现有 CLI 工具结合度高 (playwright 截图 → 直接存到 evidence/)
- 用户感知最强 (看得见摸得着的产出)

**再做方向 5 (调解谈判)**:
- 律师函的延伸, 复用现有模板
- 赔偿计算器是高频需求

**最后做方向 4 (法律检索)**:
- 数据源接入复杂 (裁判文书网反爬 / API 申请)
- 增值空间大但 ROI 不如前两个方向
