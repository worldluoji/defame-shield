# 法律免责声明

**请仔细阅读本免责声明。使用 defame-shield 工具即视为您已知晓并同意以下条款。**

## 1. 工具性质

defame-shield 是一款**辅助性文书生成工具**,其作用是:

- 基于用户提供的案件事实和预设的法律文书模板,自动生成 Markdown 格式的文书初稿
- (可选) 通过大型语言模型 (LLM) 对初稿进行润色、提升专业度
- 辅助用户整理案件信息、准备法律文书

## 2. 不构成法律意见

**本工具生成的所有内容均不构成律师法律意见、法律建议或任何形式的法律服务。**

- 工具不判断案情胜败
- 工具不评估证据充分性
- 工具不提供应诉策略
- 工具不替代律师执业

## 3. 不替代执业律师

**涉及名誉权诉讼的, 特别是: 标的额较大、事实复杂、可能涉及刑事自诉、对方已委托律师等情形, 请务必咨询执业律师。**

理由:

- 律师函/起诉状的措辞、用语、法律观点的选择, 直接影响案件走向
- 律师对当地法院的裁判倾向、对方当事人的预期反应有经验判断
- 律师能对**证据是否充分**做实质审查
- 律师能针对**诉讼策略**给出建议 (是诉前调解、还是直接起诉、还是先刑后民)

## 4. 事实真实性责任

**用户必须对输入的事实摘要、证据信息、诉讼请求的真实性、合法性承担全部责任。**

- 虚假陈述可能构成**诬告陷害**、**虚假诉讼**等违法犯罪
- 捏造证据可能构成**帮助伪造证据罪**
- 上述行为与本工具无关, 由用户自行承担法律责任

## 5. 法条引用准确性

本工具内置模板引用了以下法律条文:

- 《中华人民共和国民法典》 第 1024 条 (名誉权侵害的认定)
- 《中华人民共和国民法典》 第 1025 条 (新闻报道、舆论监督的免责事由)
- 《中华人民共和国民法典》 第 1183 条 (精神损害赔偿)
- 《最高人民法院关于审理名誉权案件若干问题的解答》 (法发〔1993〕15 号)
- 《最高人民法院关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的规定》 (法释〔2014〕11 号)

**以上条文引用为工具内置参考, 实际诉讼中请以最新颁布/修订版本为准, 并由执业律师核实。**

## 6. LLM 输出风险

**当使用 LLM 增强模式 (默认) 时, LLM 可能产生错误信息, 包括但不限于:**

- 编造不存在的法律条文
- 引用过期/已废止的司法解释
- 杜撰案例
- 对事实做不当补充

**用户应自行核实 LLM 生成的所有内容, 不应直接采信。**

## 7. 文书送达与执行

本工具**不涉及**以下法律服务:

- 文书送达 (建议使用 EMS 邮政特快专递并保留底单)
- 法院立案 (需要当事人或律师本人前往)
- 证据公证 (需要公证处办理)
- 财产保全 (需要向法院申请)
